# Negotiation

Negotiation is a big part of putting participants in relation with each other, so that they can join projects and agree on how their offers will be used. There are two ways to negotiate: project negotiation and peer-to-peer negotiation.

## Project negotiation

Project negotiation is a required step to get the project contract signed. Once the contract is signed, it enables data exchanges between the participants of that contract.

Without a project contract, the data exchange protocol cannot be enforced, and no data exchange can run within the context of the project.

If you are an orchestrator (project leader), start by learning how to [invite offers](./invitations.md).

If you are a provider who wants to join a project, start by learning how to [join a project](./join-requests.md).

Once you are comfortable with this, learn how to [review a negotiation](./negotiation.md). To follow the negotiations of a project, see [Follow your negotiations](./following-negotiations.md). A finished negotiation can be opened again: see [Restart a negotiation](./restarting-a-negotiation.md).
