# Creating a Project

https://drive.google.com/file/d/1cFo5cUDDg6LyVkxU-Dposkk8Ib9kRPNB/preview

There are multiple ways to start creating a project, the easiest of which being by going to "My Projects" available in the navigation sidebar, which will take you to the page displaying all your existing projects and the necessary action buttons to start creating a new project. You can also create a project from the basket, at [step 2](../basket/basket-steps.md#step-2-assign-to-project).

## Starting the creation of your project

On the My Projects page, there is a button at the top right of the page to start creating your project. This will open the creation page, which guides you through 2 steps to register the essential information for your project. The guide on the left explains each step and shows a preview of your project as it appears in the catalogue.

![My Projects Page](../../images/projects.png)

### Category selection

In the first step, you define what category this project fits into. This is useful for multiple reasons:

- Being able to find your project in the catalogue when filtering by category
- Enabling recommendations of offers & participants based on the defined category

### General Information registration

In the first step, you also enter the basic information for your project, such as its title, caption for the catalogue, description, location and an optional image for display in the catalogue.

If you don't set an image for your project, your logo will be used instead.

![Creating a project, step 1](../../images/creating-a-project-step1.png)

Click the **Continue** button to go to the second step, or the **Create as draft** button to save the project and finish it later.

### Searched data & services

Selecting what kind of data and/or services your project is in need for is no longer part of the creation. You can do it at any time in the project settings, under "Resources you need". As for the category selection, this is essential for the same reasons:

- Categorizing your project in the right filters
- Making sure you get recommended offers that are of the searched data / service categories
- Making sure your project gets recommended to participants that provide offers of what your project is in search for

## Governance and clauses

The second step defines why the project processes data, and the contract clauses that every participant accepts when joining the project. To complete it:

1. Fill in the "Governance" section: the project purpose, the project benefit and the project treatment.
2. Fill in the "Additional clauses" section. It has 9 clauses (reversibility / exit, subcontracting / third-party transfer, security incident notification, intellectual property on outputs, governing law & jurisdiction, force majeure, audit right, confidentiality and amendment / modification). For most of them, you choose a value in a drop-down list.
3. Click the **Continue** button to create the project.

![Creating a project, step 2](../../images/creating-a-project-step2.png)

### Using a template

You don't have to fill in every field yourself. Each section has a **Fill default template** button, which opens a window to fill the section from a ready-made set of values. Every value stays editable afterwards.

- **Dataspace template**: the values the data space recommends, aligned with what other participants expect.
- **My template**: your own saved preferences, which you set in "My Contracts", in the "Project template" tab.

![Adopt a default template](../../images/creating-a-project-template.png)

### Required fields and drafts

The two sections are marked "Required to create". The **Continue** button creates the project as a draft, and its page opens. If you want to save your progress without completing the required fields, click the **Create as draft** button instead. The project page shows its completion percentage, and the sections still incomplete are highlighted.

Once all the information has been set, you can create your project and move on to [managing your project](./project-settings.md).
